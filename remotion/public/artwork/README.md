# Original generated contextual artwork

`composition-carwash.webp` is original artwork created with the built-in image generation tool for this project. It supplies context, not exact mathematics. Exact labels, counts, graphs and equations are rendered by code.

Prompt: Premium editorial 3D illustration of a small turquoise compact car moving through two separate car-wash stations in a clean architectural studio: a soap-and-brush station followed by an air-dryer station. Clear left-to-right arrangement, recognizably distinct stages, sophisticated physical materials, cream background, teal and warm orange accents, generous negative space. Wide 16:9 composition. No text, labels, equations, logos, watermarks or people. Polished lighting and crisp silhouettes. Mathematical labels and animated numbers are overlaid separately in code.
