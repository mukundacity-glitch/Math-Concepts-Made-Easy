# Phase 4 — Step 4: Word-synchronized narration caption overlays

This step replaces the central teaching panel's placeholder **only when all
chapters have valid real Manim scene files and original Cell-3 audio**.
No math is recomputed, recolored, or re-typeset by Remotion.

## How to prepare the optional media package

After a lesson has already been generated by the existing Manim/Cell-3
pipeline, run the standalone bridge **manually** from repository root:

```bash
python -m pipeline.remotion_bridge \\
  --script output/scripts/lesson_043_script_timed.json \\
  --renders-dir output/renders/lesson_043 \\
  --audio-dir output/audio/lesson_043
```

This example shows the filename convention, not permission to rerender Day 43.
Use the *actual* lesson number and existing local files. No change is made to
the normal daily publishing pipeline.

The command prints an exported JSON props file path, for example
`remotion/build/bridged/lesson-043-<digest>.json`. The original Manim MP4s and
spoken Cell-3 MP3s are copied **byte-for-byte** into the ignored directory
`remotion/public/manim/lesson-043-<digest>/`. A new content digest produces a
new directory instead of overwriting older exports.

In `remotion/`, preview with the prepared props:

```bash
npm install
npm run check
npx remotion still src/index.ts PremiumLesson build/bridge-check.png \\
  --frame=120 --props=build/bridged/lesson-043-<digest>.json
npm run studio
```

Remotion Studio's default demo contains layout-only placeholders; load the
generated props or pass them through Remotion CLI to view staged lesson media.

## Exact timing and media contract

- Every `scene_{NN}_{step}.mp4` must exist and have a real video stream.
- Every original `scene_{NN}.mp3` must exist and have a real audio stream.
- The timed script supplies genuine `duration_seconds` from Cell 3.
- FFprobe verifies audio does not run beyond its scene, Manim frames cover
  the declared duration and neither clip has suspicious timing drift.
- Clip frame counts come from measured media lengths, rounded **down** to
  existing playable frames, with strict audio-tail protection.
- Audio is deliberately *muted inside the video* and played once via the
  original MP3, aligned at the beginning of the corresponding chapter Sequence.
- Scene order is exactly the order of the timed script. Intro/outro frame counts
  are explicit. The existing poster/header/sidebar/styling remain unchanged.
- Remotion clips use `objectFit="contain"` so verified equation symbols are
  not cropped or distorted. Their original pixels and semantic colors survive.
- One invalid/missing clip fails closed; no silent replacement of a missing
  mathematical scene with a placeholder is permitted for an attached package.

## Verification and explicit limits

`tests/test_remotion_bridge.py` creates **two FFmpeg-generated color fixtures**
with separate original audio, tests complete/partial exports, hash equality,
audio/video duration checks and idempotency. The independent Remotion CI
workflow previews two connected panels from the fixture and validates their
colors and frame size. **These synthetic fixtures are transport tests, not
real Manim lesson visuals or the full hybrid demonstration.**

The optional bridge never modifies `autopilot.py`, uploads, lesson history,
`state/progress.json`, the daily GitHub Actions publisher or Cell 5 assembly.

### Step 4 — Caption overlays from existing Cell-3 speech

The bridge now automatically reads each **original**
`audio/lesson_NNN/scene_XX.words.json` word-boundary file (Edge-TTS source)
alongside its scene's Manim MP4 and original MP3.

- Captions use Remotion's JSON `Caption` schema:
  `text`, `startMs`, `endMs`, `timestampMs`, `confidence`,
  `pageBreakAfter`. Timestamps are **relative to each original scene**,
  not absolute to the whole lesson. Per-chapter `Sequence` clocks prevent
  drift when chapter durations differ.
- Punctuation, length and duration limits group original spoken words
  into short readable caption pages, without re-transcribing or creating
  invented mathematical statements.
- Each caption page appears only during its verified word-time window.
  The **reserved caption strip below the Manim panel** never overlays
  equations, diagrams or semantic mathematical colors.
- Manim video remains muted and original Cell-3 narration plays once.
- Word-source SHA-256 contributes to the content-addressed package ID.
  A changed narration transcript therefore cannot reuse stale caption
  packages.
- If **all** word-boundary sources are missing or empty (for example
  an older gTTS fallback), the Step-3 video can still be previewed with
  captions explicitly unavailable. No speech timing is guessed.
  A **partially captioned lesson fails** instead of silently omitting
  captions for individual chapters.
- To require full caption coverage, add `--require-captions` to the
  command. Missing original timestamps then abort the export.

These are optional development previews, not live publishing.

**Not implemented yet:** vertical Shorts, a complete real nine-stage hybrid
lesson demo, production rollout, or a duplicate publishing path.

SHA-256 `466db2f838a17ef9978ccf79bd0459622bf20704904e0f2db0c52d28fe9c61f0`).

it in `remotion/build`, `output`, `state`, or ignored media directories.

chapter and outro slide, and by the Manim `make_header` for all eight
post-opening scenes. Manim's opening title uses the same asset directly.
`ScaffoldDiagnostics` also shows the canonical logo.

text / shapes (not `VGroup`, which requires VMobjects). The current daily
publishing workflow and past uploaded lessons remain untouched. The new logo
takes effect on subsequent renders only; Phase 4 Step 5 Shorts must reuse the
same `BrandLogo` component instead of inventing another asset.
